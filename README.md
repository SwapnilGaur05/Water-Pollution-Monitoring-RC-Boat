# Water Pollution Monitoring Using RC Boat

## Overview
An affordable, Arduino-based remotely operated boat designed to monitor water clarity (turbidity) in real-time. The system utilizes Bluetooth wireless communication for movement control (forward/backward) and real-time data transmission to a mobile application.

## Key Features
- **Real-Time Turbidity Monitoring:** Detects suspended solids and pollutants in water bodies.
- **Wireless Bluetooth Navigation:** Controlled using an HC-05 module and mobile application.
- **Dual Motor Propulsion:** Managed via an L9110S motor driver for locomotion.
- **Cost-Effective Design:** Built using accessible components and lightweight chassis materials.

## Hardware Components
- Arduino Uno Microcontroller
- HC-05 Bluetooth Module
- Turbidity Sensor
- L9110S Motor Driver
- DC Motors with Propeller Fans (x2)
- 9V Power Supply (x2)
- Lightweight Chassis (Thermocol & Cardboard)

## Software Requirements
- Arduino IDE
- Bluetooth Terminal / Mobile Control Application
